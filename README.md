Forecasts each GTA VI PS5 trophy's Exophase earn rate at the case's target from the read history: a recency-weighted logit-trend fit per trophy, slopes shrunk toward the cross-trophy median, extrapolated with damping, and quantile spreads from the fit residuals plus a horizon term. Pure Python 3 standard library, deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
